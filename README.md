# TechMarket Online

Tienda de tecnología con carrito, inicio de sesión y panel de administración.

- `index.html` (raíz): versión demo para GitHub Pages, sin servidor (datos en el navegador).
- `backend/`: versión con Node.js + SQL Server.
  - Local: ejecutar `TechMarket_SQLServer.sql` en SSMS, copiar `.env.example` a `.env`, `npm install`, `npm start`.
  - En internet (Render + Azure SQL): ver `DEPLOY.md`.
