# Correr TechMarket 100% en línea con GitHub Codespaces
1. En el repositorio: botón verde **Code → Codespaces → Create codespace on main** (la primera vez tarda varios minutos).
2. En la terminal del codespace: `cd backend && npm run setup-db && npm start`
3. Pestaña **Ports** → clic derecho en el puerto 3000 → **Port Visibility → Public** → copia el enlace.
